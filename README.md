Phân tích lỗi & Bảng Test Cases (README.md)Phân tích nguyên nhân kỹ thuật:Trong mã nguồn hiện tại, chương trình thực hiện tính toán công suất heater.power_watt = heater.voltage * heater.current; trước khi thực hiện kiểm tra an toàn quá tải. Khi xảy ra quá tải (current > 30.0f), chương trình đổi trạng thái is_active = 0 (ngắt điện) nhưng lại quên không gán lại giá trị power_watt = 0.0. Hậu quả là dù thiết bị đã tắt, biến công suất vẫn lưu giữ kết quả tính toán trước đó (7700.00 W).Cách khắc phục đúng logic là: Kiểm tra quá tải trước để chốt trạng thái hoạt động cuối cùng (is_active). Sau đó, dùng lệnh if-else kiểm tra is_active: nếu bằng 1 mới nhân công suất, nếu bằng 0 thì ép công suất về 0.0.Bảng Test Cases đối chứng:Trường hợp kiểm thửDữ liệu đầu vàoKết quả sai thực tế (Code cũ)Kết quả đúng mong đợi (Code mới)TC01: Dòng điện quá tảiV=220, I=35BậtThiết bị: TẮTCông suất: 7700.00 WThiết bị: TẮTCông suất: 0.00 WTC02: Hoạt động bình thườngV=220, I=20BậtThiết bị: BẬTCông suất: 4400.00 WThiết bị: BẬTCông suất: 4400.00 W
